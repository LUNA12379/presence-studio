처음 오셨네요! Application ID를 저장하면 Discord와 연결할 수 있어요.

Discord 개발자 페이지 ↗의 New Application에서 Discord에 표시하고 싶은 이름으로 앱을 만들고 General Information의 Application ID를 복사하세요. 비밀번호나 봇 토큰은 필요 없어요.

자동 감지와 다른 앱 이름을 쓰려면 두 번째 애플리케이션을 만드세요. 예: 기본 앱은 YouTube, 커스텀 앱은 Presence Studio. 자동 감지는 기본 ID, 직접 꾸미기는 전용 ID를 사용해요. 비워 두면 기본 ID를 함께 사용합니다.

YouTube라는 이름을 사용할 때 주의

그 ID를 커스텀 활동에도 쓰면 게임·작업을 입력해도 앱 이름은 YouTube로 표시되고, Discord가 작은 유튜브 로고를 붙일 수 있어요. 감지 범위가 바뀌는 뜻은 아니에요. 이름을 나눠 쓰려면 위의 전용 ID를 저장하세요.
