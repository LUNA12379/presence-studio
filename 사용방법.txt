Presence Studio 2.7.0 — 내 활동, 디스코드, 오버레이를 한곳에서

언어 선택
앱 상단 또는 처음 열리는 설명서의 EN / 한국어 버튼으로 언어를 바꿀 수 있어요.
선택한 언어는 이 PC에 저장되어 앱이나 컴퓨터를 다시 켜도 유지됩니다.
기존 한국어 사용자는 한국어를 유지하고, 새 설치는 영어로 시작합니다.
작성한 제목, 프리셋 이름, 사진 이름과 Application ID는 번역하거나 바꾸지 않습니다.
영어 안내는 README.md, 한국어 안내는 README.ko.md를 열어 주세요.

빠른 시작
Start.cmd 또는 desktop\Presence Studio.exe를 실행하세요.
Discord 개발자 페이지의 New Application에서 'Discord 활동에 표시하고 싶은 이름'으로 앱을 만드세요.
General Information의 Application ID를 연결 & 설정의 '기본 Application ID'에 입력하고 'ID 저장 후 연결'을 누릅니다.
저장한 ID는 앱을 종료하거나 PC를 다시 켜도 유지됩니다.
기존 버전을 사용했다면 Discord Application ID와 Edge 확장 연결을 자동으로 가져옵니다.
이미 확장을 설치했다면 아래의 확장 설치 단계는 다시 할 필요가 없습니다.

설치 프로그램과 업데이트
- Presence-Studio-2.7.0-Setup.exe 실행 → 설치를 누르세요. 현재 사용자에게 설치하며 관리자 권한은 필요하지 않습니다.
- Node.js가 포함되어 있습니다. WebView2가 없으면 Microsoft 설치 프로그램이 실행되며 인터넷 연결이 필요합니다.
- 설치 위치: %LOCALAPPDATA%\Programs\Presence Studio. 시작 메뉴 바로가기를 만들고 바탕화면 바로가기는 선택합니다.
- 기존 ID·프리셋·사진은 유지합니다. Windows의 설치된 앱에서 제거해도 %APPDATA%\PresenceStudio의 개인 데이터는 남습니다.
- 연결 & 설정 → 앱 업데이트 → 업데이트 확인에서 새 버전과 변경 내용을 확인하세요.
- 새 버전 다운로드 → 파일 검증 완료 → 설치하고 다시 시작 순서로 진행합니다.
- '앱을 켤 때 새 버전 확인'은 확인만 자동으로 합니다. 다운로드·설치는 버튼을 눌러야 진행됩니다.
- 공개 배포처: https://github.com/LUNA12379/presence-studio-releases/releases/latest
- 배포처 미연결 상태인 초기 버전은 최신 Setup.exe를 한 번 설치하세요. 이후에는 앱에서 새 버전을 확인하고 설치할 수 있습니다. GitHub의 Source code 압축 파일은 설치 파일이 아닙니다.
- 앱 실행 시 확장 파일도 갱신합니다. 변경된 확장은 Edge 확장 관리에서 새로고침하고 YouTube 탭도 새로고침하세요.

프리셋 저장과 불러오기
- 직접 꾸미기에서 활동을 만든 뒤 '프리셋으로 저장'을 누르세요. 현재 활동 제목을 이름으로 저장하므로 별도 이름 입력은 필요 없습니다.
- 저장 버튼 아래 '저장한 프리셋' 목록에 바로 추가됩니다. 선택하면 제목, 상태, 표시 종류, 타이머 길이, 두 이미지, 링크가 함께 불러와집니다.
- 불러오기와 저장은 편집 내용만 다룹니다. Discord와 오버레이에 표시하려면 '이 활동으로 표시하기'를 누르세요.
- 불러온 내용을 수정한 뒤 '선택한 프리셋 덮어쓰기'를 누르면 기존 이름을 유지하며 같은 항목이 갱신됩니다.
- '프리셋으로 저장'은 현재 제목으로 새 항목을 추가합니다. 최대 30개이며 프리셋 메뉴에서 삭제할 수 있습니다.
- 프리셋 메뉴의 '바로 적용'은 즉시 활동을 바꾸고, '불러오기'는 직접 꾸미기에서 내용을 확인·수정할 수 있게 합니다.
- 프리셋과 이미지 선택은 앱·PC를 다시 켜도 유지됩니다. 타이머는 설정한 길이를 저장하며 활동 적용 시 새로 시작합니다.
- 이전 버전에서 저장한 이름과 사진은 그대로 유지됩니다.

이미지 파일로 꾸미기
- 직접 꾸미기 → 이미지 파일 선택에서 PNG, JPG, WebP를 고르거나 파일을 끌어 놓으세요.
- 자르기 창에서 드래그·방향키로 위치를 맞추고 확대 슬라이더로 원하는 부분을 고르세요. Shift + 방향키는 크게 이동합니다.
- '전체 담기 · 투명 여백'을 선택하면 사진을 자르지 않고 정사각형 안에 담습니다.
- 1024 × 1024(권장) 또는 512 × 512(최소) 크기를 고른 뒤 '이미지 보관하기'를 누르세요. 취소하면 선택과 보관함은 그대로입니다.
- 작은 원본도 지정한 크기로 확대하지만 화질이 원본보다 좋아지는 것은 아닙니다.
- 보관한 사진은 '자르기 · 크기 맞추기'로 다시 편집할 수 있습니다. 기존 파일을 덮어쓰지 않고 새 이미지로 보관합니다.
- 'PNG로 저장'을 눌러 원하는 위치에 꺼낸 뒤 Discord 등록 페이지에 그 파일을 올리세요. 브라우저에서는 다운로드 설정을 따릅니다.
- 사진은 사용자 설정 폴더의 images 폴더에 보관되므로 원본을 옮겨도 유지됩니다.
- 활동 적용 또는 프리셋 저장을 누르면 선택한 이미지도 함께 기억합니다. 다음에는 보관한 이미지 목록에서 선택하세요.
- '내 이미지 / 보관한 이미지'는 앱 미리보기·데스크톱 오버레이·OBS에 표시할 사진입니다.
- 'Discord에 표시할 이미지'는 Discord 활동 카드의 큰 사진입니다. 두 선택란에서 다른 사진을 골라도 됩니다.
- 내 이미지를 고르지 않으면 Discord 이미지나 고급 이미지 주소를 앱·오버레이에도 사용합니다.
- Discord에도 사진을 표시하려면 'Discord 이미지 등록'에서 Rich Presence → Art Assets에 파일을 올리고 저장한 뒤, 앱에서 '목록 새로고침' 후 선택해 저장하세요.
- 조회 대상 ID와 이미지를 등록한 앱이 같아야 합니다. 커스텀 전용 ID가 있으면 그 앱에 등록하세요. 새로고침은 이전의 빈 목록 대신 최신 목록을 요청합니다.
- 앱은 파일을 자동으로 외부에 업로드하지 않습니다. 필요하면 '보관 폴더 열기'에서 변환한 PNG를 찾으세요.
- 15MB 이하 원본을 512 또는 1024 정사각형 PNG로 변환하며 최대 60개까지 보관합니다.

앱을 두 개 만드는 이유
- 자동 감지와 직접 꾸민 활동을 서로 다른 앱 이름으로 표시하기 위한 기능입니다.
- 자동 감지용 앱을 예를 들어 YouTube라는 이름으로 만들고 '기본 Application ID'에 저장하세요.
- 커스텀 활동용 앱을 Presence Studio 등 원하는 이름으로 하나 더 만들고 '커스텀 활동 전용 Application ID'에 저장하세요.
- 자동 감지는 기본 ID, 커스텀 활동은 전용 ID로 자동 연결됩니다. 같은 이름을 사용해도 되면 앱 하나만 만들고 전용 ID를 비워 두세요.
- 주의: 앱 이름이 YouTube이고 같은 ID를 커스텀 활동에도 쓰면, 게임·작업을 입력해도 앱 이름이 YouTube로 표시되고 작은 유튜브 로고가 붙어 유튜브 활동처럼 보일 수 있습니다.
- 이름 때문에 실제 감지 범위가 제한되는 것은 아닙니다. 작은 로고는 Discord가 이름을 보고 붙이는 플랫폼 표시이며 App Icon이나 직접 선택한 큰 사진과 별개입니다.
- 저장한 두 ID는 앱이나 PC를 다시 켜도 유지됩니다.

설명서
- 시작하기, 이미지 자르기·등록, 두 앱의 이름과 아이콘, 프리셋, 설치·업데이트, 오버레이를 설명하는 6단계 설명서가 앱을 열면 나타납니다. 마지막 페이지의 '앱을 켤 때 다시 표시하지 않기'를 체크하고 '저장하고 시작하기'를 누르면 다음 실행부터 숨깁니다.
- 연결 & 설정 → 설명서 보기에서 언제든 다시 열 수 있습니다.
- 다시 시작할 때 보려면 설명서 마지막 페이지의 체크를 해제하고 저장하세요.

통합 앱의 새 기능
1. 지금 내 활동: YouTube / YouTube Music 자동 감지, 현재 공유 상태, 탭 선택과 고정
2. 직접 꾸미기: 제목, 상태 문구, 활동 종류, 이미지, 링크 버튼, 경과/남은 시간
3. 오버레이: 바탕화면/창 모드 게임 위의 작은 카드 + OBS 브라우저 소스
4. 프리셋: 나만의 수동 활동을 이름으로 저장하고 한 번에 적용 (최대 30개)
5. 연결 & 설정: 채널/제목 키워드 제외, 일시정지 숨김, 자동 실행, 연결 상태

오버레이 사용
- 오버레이 메뉴 → 데스크톱에 표시를 켭니다.
- 다른 창 위의 작은 카드를 마우스로 드래그해서 옮길 수 있습니다.
- 미드나잇 / 라이트 / 컴팩트, 강조색, 너비, 불투명도, 이미지, 재생 시간을 조절합니다.
- 위치 잠금은 드래그를 막고, 클릭 통과는 카드 아래의 창으로 마우스 입력을 보냅니다.
- 위치를 잃어버렸다면 앱의 '위치 초기화'를 누르세요.
- 전체 화면 전용 게임은 위에 표시하지 못할 수 있습니다. 창 모드/테두리 없는 창 모드를 사용하세요.

OBS 사용
- 오버레이 메뉴에서 OBS 주소를 복사합니다.
- OBS → 소스 추가 → 브라우저 → URL에 붙여넣습니다.
- 너비와 높이는 앱에서 표시하는 값으로 입력하세요. 기본 400 × 148, 컴팩트는 높이 96입니다.
- 배경은 투명합니다. 앱의 활동 공유가 꺼지거나 활동이 없으면 자동으로 숨겨집니다.
- 데스크톱 오버레이 표시 여부와 OBS 표시 여부는 별개입니다.
- OBS 주소는 표시 전용입니다. 설정 변경용 연결 키를 포함하지 않습니다.
- OBS가 있는 같은 PC에서 Presence Studio를 실행하고 있어야 합니다.

빠른 조작
- Ctrl+Shift+P: 전체 활동 공유 켜기/끄기 (Discord와 오버레이)
- Ctrl+Shift+O: 데스크톱 오버레이 켜기/끄기
- 창의 X 버튼: 트레이로 숨김. 시계 옆 아이콘을 더블클릭하면 다시 열립니다.
- 완전 종료: 트레이 메뉴 → 종료 또는 연결 & 설정 → Presence Studio 종료
- 자동 실행: 연결 & 설정에서 Windows 로그인 시 자동 실행을 켜고 저장합니다.
- 단축키가 다른 앱에 등록되어 있다면 연결 & 설정에서 알리고, 트레이 메뉴를 사용할 수 있습니다.

수동 활동 참고
- '이 활동으로 표시하기'를 누르면 자동 감지보다 우선 표시됩니다.
- '지금 내 활동 → 자동 감지'로 돌아가면 다시 유튜브 정보를 표시합니다.
- 이미지는 파일 또는 Discord 등록 목록에서 고르세요. 고급 이미지 주소와 링크 버튼에는 https:// 주소를 사용합니다.
- Discord 상단의 앱 이름은 개발자 페이지의 Application 이름을 따릅니다.
- 나머지 프로그램이나 웹사이트를 자동으로 감지하는 기능은 이 버전에 포함하지 않습니다. 수동 활동으로 설정할 수 있습니다.

기존 유튜브 연결 안내

실행
1. Start.cmd를 더블클릭하면 통합 데스크톱 앱이 열립니다.
2. Edge 주소창에 edge://extensions 를 입력합니다.
3. 개발자 모드를 켜고, '압축 풀린 확장 로드'를 선택합니다.
4. 앱의 연결 & 설정 → Edge 확장 연결에서 '폴더 경로 복사'를 누르고 그 폴더를 선택합니다.
   기본 경로: %APPDATA%\PresenceStudio\edge-extension
5. 이미 열려 있던 YouTube / YouTube Music 탭을 새로고침한 뒤 영상을 재생합니다.
6. Discord 데스크톱 앱의 사용자 설정 → 활동 개인정보에서 활동 공유를 켭니다.

Windows 10/11 x64와 Node.js 20 이상이 필요합니다.
추가 npm 패키지 설치는 필요하지 않습니다. Edge WebView2 Runtime과 .NET Framework 4.7.2 이상을 사용합니다.
확장은 사용자 설정 폴더에 있어서 프로그램 폴더를 옮겨도 유지됩니다.
앱 업데이트 후 Edge 확장 관리에서 확장을 새로고침하면 새 코드가 적용됩니다.

표시되는 내용
- 영상 또는 곡 제목, 채널/아티스트, 썸네일, 재생 시간, 영상 열기 버튼
- 기본값: YouTube는 시청 중, YouTube Music은 듣는 중
- 설정에서 '게임처럼 플레이 중'으로 변경 가능
- 여러 탭이 재생되면 가장 최근에 재생을 시작한 탭을 우선
- 일시정지 1분 후 숨김 (설정에서 즉시 / 30초 / 1분 / 5분 선택)
- 영상 종료, 페이지 이동, 탭 닫기는 다음 갱신 시 활동 제거
- 연결 이상이나 절전 시 마지막 수신 후 최대 약 95초 뒤 오래된 활동 제거
- 광고 감지 시 활동을 숨깁니다. YouTube 페이지 구조 변경에 따라 감지 수정이 필요할 수 있습니다.
- 라이브 영상에는 잘못된 남은 시간이 표시되지 않도록 재생 타이머를 생략합니다.

사용 중
- 설정 창을 닫아도 트레이에서 프로그램은 계속 실행됩니다.
- 확장 아이콘을 누르거나 http://127.0.0.1:49832 에 접속하면 설정을 다시 엽니다.
- 표시만 잠시 끄려면 설정 화면 오른쪽 위 '활동 공유'를 끕니다.
- 완전히 종료하려면 트레이 메뉴의 '종료'를 누릅니다.
- Windows 로그인 시 자동 실행하려면 Enable-Autostart.cmd를 한 번 실행합니다.
- 자동 실행 해제는 Disable-Autostart.cmd입니다. 앱의 연결 & 설정에서도 관리할 수 있습니다.

Discord 설정
- 배포본에는 Application ID가 비어 있습니다. 각자 https://discord.com/developers/applications 에서 애플리케이션을 만들고 General Information의 Application ID를 입력하세요.
- 'ID 저장 후 연결'을 누르면 이 Windows 사용자에게 저장됩니다. 비밀번호, 봇 토큰, 사용자 토큰을 사용하지 않습니다.
- 활동의 앱 이름은 Discord 개발자 페이지에서 해당 Application의 이름으로 결정됩니다.
- 친구에게 보이는 상태는 Discord의 활동 공유 / 서버별 개인정보 / 온라인 상태 설정에도 영향을 받습니다.
- 영상 링크 버튼은 Discord에서 본인 프로필을 볼 때와 다른 사람이 볼 때 다르게 표시될 수 있습니다.
- 데스크톱 Discord가 필요합니다. 브라우저 Discord만 실행한 상태로는 동작하지 않습니다.

데이터
- 확장은 www.youtube.com, music.youtube.com에서만 재생 정보를 읽습니다.
- InPrivate에서는 실행하지 않습니다. 브라우저 방문 기록, 쿠키, 비밀번호를 읽지 않습니다.
- 재생 정보는 127.0.0.1의 연결 프로그램을 거쳐 실행 중인 Discord로 전달됩니다.
- 영상 정보는 메모리에만 유지하고 시청 기록 파일을 만들지 않습니다.
- Discord 및 앱과 오버레이에서 이미지를 표시할 때 해당 이미지 서버에 요청합니다.
- Application ID, 직접 입력한 활동, 프리셋, 오버레이 설정은 %APPDATA%\PresenceStudio\config.json에 저장됩니다.
- 이 폴더는 앱을 종료하거나 PC를 다시 켜도 유지됩니다. 프로그램 업데이트와 개인 설정은 분리되어 있습니다.
- 사용자 설정과 edge-extension/connection.js의 연결 키는 이 PC의 확장과 프로그램을 짝짓는 키입니다.
- 구버전 폴더의 config.json은 사용자 설정이 없을 때만 가져오며 원본을 삭제하지 않습니다.

배포용 ZIP 만들기 (소스 저장소에서)
- 앱을 완전히 종료한 뒤 PowerShell에서 .\Package.ps1을 실행합니다.
- dist 폴더에 개인 설정과 연결 키를 제외한 ZIP이 생성됩니다.
- 프로그램 폴더를 통째로 압축하는 대신 이 패키징 명령을 사용하세요.
- 새 PC에서는 앱을 먼저 실행하고 Application ID를 저장한 뒤 앱이 안내하는 확장 폴더를 로드합니다.

삭제
1. 트레이 메뉴에서 프로그램 종료
2. 자동 실행을 사용했다면 Disable-Autostart.cmd 실행
3. edge://extensions 에서 'YouTube → Discord 활동' 제거
4. 프로그램 폴더 삭제
5. 개인 설정도 지우려면 %APPDATA%\PresenceStudio 폴더를 삭제 (선택)

공식 문서

SoundCloud 사용하기
- 앱 업데이트 후 Edge 또는 Chrome 확장 관리에서 Presence Studio — YouTube & SoundCloud 확장을 새로고침하세요.
- SoundCloud 접근 권한을 확인하고 SoundCloud 탭을 새로고침한 다음 곡을 재생하세요.
- 곡명·아티스트·커버·시간과 일시정지를 읽으며, 자동 활동 종류는 듣는 중입니다.
- 여러 재생 탭 중 마지막으로 재생을 시작한 탭이 우선이며, 이 탭 고정으로 고정할 수 있습니다.
- 기존 Application ID는 유지됩니다. 앱 이름이 YouTube라면 SoundCloud 활동도 그 앱 이름 아래에 표시됩니다.
- 브라우저 웹사이트만 지원하며 비공개 곡 링크는 공유하지 않습니다.
